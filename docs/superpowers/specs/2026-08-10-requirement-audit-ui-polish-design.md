# 海福来外贸报价系统：历史需求复核与 UI 收口

## 目标

在不改变现有蓝白视觉体系和主流程的前提下，复核此前需求是否真正可用，补齐数据、交互和视觉细节，并重新发布线上版本。

## 本轮范围

1. 阻止数量、表头、年份等非型号内容进入联网搜索和二次校对。
2. 将现有错误待校对项安全标记为已驳回，保留审计记录，不硬删除。
3. 去重并精简外网证据，避免重复链接和大段网页源码干扰判断。
4. 让通知和用户入口具备真实展开状态；通知可直达二次校对。
5. 补充当前页面标记、键盘焦点、按钮悬停、下拉层级和小字号可读性。
6. 保持型号、报价、校对、知识库已有能力与下载格式不变。

## 视觉原则

- 延续现有 HIFLY 蓝、白色卡片、浅灰背景和圆角体系。
- 重要信息优先：型号、OE/UF、待处理数量和主操作保持高对比。
- 仅做保守优化，不重构布局，不引入新的视觉风格。
- 所有显式按钮都应有可理解的反馈或真实动作。

## 验收

- 无效输入不会产生新校对项，已有无效项不再出现在待处理队列。
- 外网来源不重复，摘要为短文本，不展示网页源码。
- 通知与用户菜单可打开和关闭，通知能进入二次校对。
- 键盘可看见焦点，侧栏能表达当前页面。
- 构建通过，生产环境五个主要页面逐页复核。
